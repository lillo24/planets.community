# PLANETS web bootstrap

This folder owns the Next.js public website and the future authenticated admin surface.

- `src/app/` contains the App Router layout, page, and global styles.
- `next.config.ts`, `eslint.config.mjs`, `postcss.config.mjs`, and `tsconfig.json` are framework/tool configuration.
- `package.json` exposes `dev`, `build`, `start`, `lint`, and `typecheck`.

Node dependencies and the canonical lockfile are owned at the repository root. Run web commands through `npm run dev:web` and `npm run check:web` from there.
