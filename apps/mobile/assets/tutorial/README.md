# Tutorial illustration cover

`garden-tools.webp` is an unchanged copy of the existing licensed demo cover at
`scripts/demo-assets/covers/garden-tools.webp`, now bundled for tutorial-only
offline illustrations. It depicts tools and plants, with no attribution to a
PLANETS user or real listing. Every example is visibly labelled.

- Photographer: Gary Barnes, [source photo](https://www.pexels.com/photo/various-gardening-tools-with-plants-and-opened-book-6231722/).
- License: [Pexels license](https://www.pexels.com/license/).
- Retrieved: 2026-09-29; normalized to 1280×720 WebP, stripped of metadata.
- SHA-256: `0e8a0b1110b731de8aa737d7a4eb4b8545e209325bc79321b46b80e4983ed5c2`.

The original provenance record is `scripts/demo-assets/assets.json`.
The tutorial uses this bundled asset only when no accessible public card/detail
is available within its bounded read. No synthetic record is written to backend
data, and normal public covers continue through the existing media widgets.
