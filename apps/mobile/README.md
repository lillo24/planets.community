# PLANETS mobile bootstrap

This folder owns the Flutter application and its generated Android/iOS platform projects.

- `lib/main.dart` contains the neutral bootstrap application.
- `test/widget_test.dart` verifies that the bootstrap screen renders.
- `android/` and `ios/` contain conventional Flutter-generated platform configuration.
- `pubspec.yaml` owns Dart and Flutter dependencies.

Run mobile commands from the repository root through `npm run dev:mobile` and `npm run check:mobile`. The current application identifiers are provisional; see the repository [getting-started guide](../../docs/development/getting-started.md#provisional-mobile-identifiers).
