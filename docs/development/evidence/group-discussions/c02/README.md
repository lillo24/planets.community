# C02 native frames

These EN/IT frames were captured on the C-owned Android emulator (1080×2400),
against the C-owned loopback Supabase stack with verified fictional OTP identities.
They show explicit invitation consent, frozen lost-send recovery, current room
chat, the existing Group detail entry and the independent Messages folder.

The final on-device journey passed, including one committed send after retry and
server denial after Leave. Its host driver's final result/screenshot export failed
with `Service connection disposed`; these frames come from the earlier identical
visual steps. The later scrolling/receipt fixes changed transition safety, not the
rendered layouts. No real personal data or external provider account is shown.

320px / 200% EN/IT light/dark and folder semantics are covered by widget tests.
Physical Android, iOS and TalkBack were not run.
