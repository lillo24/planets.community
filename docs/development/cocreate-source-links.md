# Explicit source links (D02)

Post, numbered room and native personal Project remain independent objects. The
experimental conservative authorization default requires both post authorship
and current numbered-room creatorship to attach a group. References are private
to author management and active accepted post contacts. They contain only the
current public group's number, broad topic/locality and aggregate capacity.
No reference grants admission, transcript, roster or native Project authority.

`mutate_cocreate_post_group` binds actor, command, exact post version and room
episode. It serializes with the B01 post actor and C03 room actor/hub locks, then
the author's post row. Link/clear increments the ordinary post version and its
metadata invalidation. An unavailable destination retains a non-actionable
marker without current counts. Source changes never rewrite public text, private
notes, accepted conversations or memberships. Closing a post does not destroy
existing accepted contacts. Closing a contact removes its continuing group option.

An author can deliberately browse Communities, join one, create a numbered group,
return and explicitly choose it. No stage auto-joins the hub or child or auto-links
the result. The picker filters current manageable groups on the server before
paging. Accepted respondents review history/audience and use the canonical C03
admission. Protected Messages review routes preserve this deliberate flow when
the local Sandbox presentation switch is OFF, without an Auth/policy exception.

`create_cocreate_project_draft` requires the current numbered creator for a new
command, then calls the existing native `create_editor_proposal_draft` with sparse
empty content and ordinary defaults (Europe/Rome timezone, participant-only
exact location visibility, no capacity, no organizer counting). No title, notes,
chat, roster or location is copied. Only a private proposal/room/creator reference
is recorded. Native Project editing/publication and retention stay authoritative.
Native draft command identities cannot be repurposed to a different source intent.

Exact recovery can identify an already-created personal draft after creator
departure; an old episode cannot create a new one. Missing native destinations
fail P0002. The source FK cascades on native deletion rather than adding a deletion
restriction; native receipt/retention rules still apply. Cancel/back follows the
ordinary editor flow, with the existing private return marker and no automatic
publication, enrollment or source-room mutation. Unpublished personal drafts are
not listed to the group: native public reads decide every published link.

RAM command attempts also retain an acknowledged receipt until UI completion
succeeds. If navigation/refresh fails after acknowledgement, Retry completes that
UI step from the identifier-only receipt without sending another write. New
destinations still reread canonical authority. Actor/realm changes clear attempts;
completion only clears the exact original attempt, never another actor's work.

Reproduce with `npm run cocreate:links:verify:local` on the owned disposable stack.
It uses genuine OTP accounts and verifies explicit consent, no enrollment,
concurrent source CAS, immutable retries, ordinary empty native drafts, private
unpublished results, creator departure and backend-OFF native ownership. Gate
activation always returns OFF. See cocreate-progress.md for final counts.
