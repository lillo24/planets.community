## Delivered boundaries

One automatic General belongs to every eligible published Group. Managers-only
Idea creation is a reversible initial setting; authorized structural editors may
enable all members. Group-visible Ideas expose eligible summaries before Join;
restricted Ideas disclose their current-manager audience. Actual admissions and
oversight scopes remain separate records and close independently.

Current manager oversight permits reading, sending and managing inside the
Group Idea without creating ordinary room participation. Managers may explicitly
join separately; oversight alone is not a planner admission or Project grant.

Current General/admitted Idea readers receive full earlier room history. Their
unread baseline begins at the new grant, and only the exact authorized rendered
snapshot advances ACK. Ended actual participation retains the committed exit
sequence and metadata snapshot; ended oversight retains its fetched frontier.
Former readers receive no current links, roster, activity, title edits or alerts.
Old already-ended C episodes have no reconstructable exit snapshot: the upgrade
preserves their prior denial instead of fabricating current metadata as history.

Messages folders compose independently entitled Projects and General & Ideas
before limits. Visual Project aliases do not create a second conversation or
unread counter. Account-bound mapping preserves canonical drag pagination and
scroll anchors. Mute, manual hide and seven-day quiet classification remain
independent; General is pinned, supports mute/unmute and is never quiet-hidden.
General's one-time workspace introduction is dismissible per account on this
installation; its permanent workspace entry remains. Missing preference means
visible, failed storage remains explicit/retryable and no private content is saved.
The bounded context and composer scrollers preserve a positive history viewport
at narrow large-text sizes. Discovery shows the canonical creator identity;
authorized People adds the readable name and separate Idea creator provenance,
without granting Group authority or fetching a private profile before admission.

Room invitations/capabilities require deliberate acceptance and current Group
eligibility. Activity notices are bounded, reauthorized, separate from human
unread and cleared before a potentially failing access refresh. No client or
publication transaction loops over all Group recipients.

Only the actual Group Creator/Co-creator publisher owns the bound private draft.
Ordinary publication rechecks the binding and atomically freezes planning. It
copies no messages and creates no memberships, capacity reservations or roles.
Eligible planners receive bounded, idempotent public Project invitations;
opening is not joining and declining preserves independently authorized source
history. Project-only participants receive no planning origin or history.

Continuity uses the package's permitted **linked read-only planning view**
fallback, followed by the ordinary Project view. It is not a single interleaved
timeline. Both histories retain their own pagination, reports, ACK and access
checks. Selected link sharing requires current source rights and canonical
Project-manager authority, with destination review and exact retry recovery.
An open sharing confirmation removes its private text and action when its
account, source episode/item or destination rights change. Pending sharing
survives route remounts in memory; Close remains guarded until recovery or a
definitive cancellation. Retrying reuses the exact UUID and reviewed intent.

The source/Project permission boundary remains explicit in the linked-view
fallback. The private origin resolver requires canonical Project history rights
and a source frontier covering the frozen publication sequence; it rechecks both
when the entry is activated. A source grant never creates a Project grant.

| Viewer                                              | Planning source                                                                                                             | Project side and continuity                                                                                                                        |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Planner who deliberately joins the Project          | Independently authorized frozen history; current links require current source access                                        | Canonical Project history/composer; private planning button opens a separate read-only view, then returns to Project                               |
| Planner pending, ignoring or declining Project Join | Retained authorized source history                                                                                          | Truthful public Project/invitation status; no private Project message preview or human unread                                                      |
| Project-only participant                            | No source metadata, route, transcript or links                                                                              | Ordinary Project conversation; the client makes no private room/history request                                                                    |
| Group manager without Project entitlement           | Disclosed independent Group oversight                                                                                       | Public Project action context only; Group authority creates no Project chat right                                                                  |
| Project manager without source entitlement          | No source transcript or collection; no selected-link disclosure authority                                                   | Canonical Project management/chat rights only                                                                                                      |
| Former source or Project participant                | Each domain retains only its own authorized exit frontier/snapshot; suppression/unavailability can deny the source entirely | No later activity from the ended domain; a retained origin is possible only when both history checks still pass; neither domain restores the other |
